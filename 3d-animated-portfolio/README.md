## 🌟 Descripción del Proyecto

Este repositorio aloja mi portfolio personal desarrollado utilizando **React** y la potencia de **gráficos 3D interactivos** para ofrecer una experiencia única y memorable al visitante.

El objetivo es mostrar mis habilidades como desarrollador web Fullstack, destacando el conocimiento en el ecosistema React y la capacidad para integrar librerías avanzadas de visualización 3D, como **React Three Fiber (R3F)**, para crear interfaces de usuario dinámicas y modernas.

## ✨ Características Principales

* **Experiencia 3D Interactiva:** Un entorno tridimensional navegable o elementos 3D clave (como modelos de proyectos o un avatar) creados con React Three Fiber.
* **Diseño Responsivo:** Adaptabilidad a diferentes tamaños de pantalla (escritorio, tablet y móvil).
* **Secciones Clave:** Estructura clara con las siguientes secciones:
    * **Inicio:** Presentación y animación 3D.
    * **Acerca de Mí:** Habilidades técnicas y experiencia.
    * **Proyectos:** Muestra de mis trabajos (con enlaces a los repositorios).
    * **Contacto:** Formulario o información de contacto.
* **Animaciones Fluidas:** Transiciones y animaciones basadas en el *scroll* o la interacción del usuario.

## 🛠️ Tecnologías Utilizadas

El proyecto fue construido con el siguiente *stack* tecnológico:

| Tecnología | Descripción |
| :--- | :--- |
| **Frontend** | |
| **React** | Biblioteca principal para construir la interfaz de usuario. |
| **React Three Fiber (R3F)** | Un *renderer* de Three.js para React, que facilita la creación de escenas 3D. |
| **Three.js** | Librería de JavaScript para crear y mostrar gráficos 3D en el navegador. |
| **Tailwind CSS / Styled Components** | (Elegir la que uses) para el estilizado rápido y modular. |
| **Otras Librerías** | `framer-motion` (para animaciones), `vite` o `cra` (para *bundling*). |
