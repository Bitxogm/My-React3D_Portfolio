# Contribuir a My React 3D Portfolio

¡Gracias por tu interés en contribuir a este proyecto! 🎉

## 🌟 Cómo Contribuir

### Reportar Bugs

Si encuentras un bug, por favor abre un [issue](https://github.com/Bitxogm/My-React3D_Portfolio/issues) con:

- Descripción clara del problema
- Pasos para reproducirlo
- Comportamiento esperado vs actual
- Capturas de pantalla (si aplica)
- Tu entorno (navegador, OS, versión de Node.js)

### Sugerir Mejoras

Para nuevas características o mejoras:

1. Verifica que no exista un issue similar
2. Abre un nuevo issue describiendo:
   - La funcionalidad propuesta
   - Por qué sería útil
   - Ejemplos de uso

### Pull Requests

1. **Fork el repositorio**
   ```bash
   git clone https://github.com/TU-USUARIO/My-React3D_Portfolio.git
   ```

2. **Crea una rama para tu feature**
   ```bash
   git checkout -b feature/amazing-feature
   ```

3. **Haz tus cambios siguiendo las convenciones del proyecto**

4. **Asegúrate de que el código pase el linter**
   ```bash
   npm run lint
   ```

5. **Commit tus cambios**
   ```bash
   git commit -m 'feat: add amazing feature'
   ```

6. **Push a tu fork**
   ```bash
   git push origin feature/amazing-feature
   ```

7. **Abre un Pull Request**

## 📝 Guía de Estilo

### Código

- Usa **PascalCase** para componentes: `MyComponent.jsx`
- Usa **camelCase** para funciones y variables: `myFunction`
- Usa **kebab-case** para archivos CSS: `my-styles.css`
- Mantén los componentes pequeños y enfocados
- Comenta código complejo

### Commits

Seguimos la convención de [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` Nueva característica
- `fix:` Corrección de bug
- `docs:` Cambios en documentación
- `style:` Formateo, espacios en blanco
- `refactor:` Refactorización de código
- `test:` Añadir o modificar tests
- `chore:` Tareas de mantenimiento

Ejemplos:
```
feat: add 3D model loading progress indicator
fix: resolve Globe rotation performance issue
docs: update installation instructions
```

## 🧪 Testing

Antes de enviar un PR:

1. Prueba tu código localmente
2. Verifica que no hay errores de ESLint
3. Asegúrate de que el proyecto se construye correctamente

```bash
npm run lint
npm run build
```

## 🤔 ¿Preguntas?
